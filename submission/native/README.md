# Нативное приложение battery_type

В локальном комплекте рядом находится Windows exe, собранный GitHub Actions. Нужен установленный Microsoft Edge WebView2 (используется системный движок).

Сначала запустить основной API с PostgreSQL, Redis и MinIO. Адрес API в сборке: http://192.168.1.128:53000/api . Это LAN IPv4, не localhost. При смене сети нужно изменить .env.production в репозитории Battery-type-native и пересобрать.

В приложении доступны гостевой каталог, ёмкость, пагинация, Подробнее и CLIP-поиск. Кнопка обновления перечитывает данные API. Логин и публикация отсутствуют в маршрутах нативной сборки.

Результат сборки: https://github.com/NXC0BM/Battery-type-native/actions . Бинарный файл не добавляется в Git; он включён в локальный ZIP.
