# Battery Runtime — фронтенд (ЛР5)

SPA на **React + TypeScript** (сборщик **Vite**, компоненты **React-Bootstrap**, маршрутизация **react-router-dom**) для роли **гость**.
Redux и React Context не используются: общий список карточек передаётся страницам через `Outlet` context роутера.

В ЛР5 доступны только две страницы — **плитка** и **лента**. Они работают **только на mock-данных**
(`src/modules/mock.ts`) — без веб-сервиса, базы данных и S3 (MinIO).

## Запуск

```bash
cd battery-runtime-frontend
npm install
npm run dev        # http://localhost:3001 (порт 3000 занят веб-сервисом)
npm run build      # проверка типов + production-сборка в dist/
```

Веб-сервис запускать не нужно: все данные берутся из mock-коллекции.

## Страницы

Приложение свёрстано под телефон (колонка 420 px), внизу — навигационная панель.

### Навигационная панель (на всех страницах)

4 пункта, доступны только два:

| Пункт | Иконка | Для гостя |
|---|---|---|
| Лента | ▶ | доступен — переход на `/lenta` |
| Добавление | + | пока недоступен (серый) |
| Плитка | ▦ | доступен — переход на `/plitka` |
| Вход | ⎆ | пока недоступен (серый, справа) |

Активный пункт подсвечивается оранжевым по текущему адресу.

### Плитка — `/plitka` (стартовая страница, `/` перенаправляет сюда)

- Заголовок «Battery Runtime / Аккумуляторы, каталог типов аккумуляторов».
- **Фильтр «Ёмкость от, мА·ч»** — слайдер 0…5000 с шагом 100, рядом число выбранного значения.
- **Кнопка «Показать»** — применяет фильтр к mock-коллекции (ёмкость не меньше выбранной).
  Пока идёт загрузка — спиннер, кнопка заблокирована.
- **Карточки** в 2 колонки: изображение (или изображение по умолчанию), название модели, ёмкость, число лайков.
  Нажатие на карточку — переход в ленту на эту карточку (`/lenta/:id`).

### Лента (страница «подробнее») — `/lenta`, `/lenta/:id`

- **Видео на весь экран** — видео и изображение по умолчанию `public/DefaultVideo.mp4`, `public/DefaultImage.jpg`,
  если в услуге поле пустое (в mock поля пустые) или ссылка не открывается.
- Название модели, ёмкость (мА·ч) и номинальное напряжение (В).
- **Краткое описание** — обрезается, кнопка **«Ещё»** раскрывает его полностью.
- **Дополнительные характеристики (EAV)** — список «атрибут — значение — единица измерения»
  (химия, макс. ток разряда, масса, типоразмер, ресурс) — в mock в том же виде, что отдаёт веб-сервис
  из таблиц `attributes` и `battery_type_attributes`.
- **♥ и число лайков** — для гостя только просмотр.
- **Кнопка «→» (Далее)** — следующая карточка в порядке плитки (после последней — снова первая).

Данные карточки берутся из mock-коллекции по `id` из адреса.

## Структура

```
src/
  main.tsx, App.tsx        точка входа и маршруты
  Routes.tsx               адреса страниц и подписи пунктов меню
  AppLayout.tsx            общая обёртка: список карточек (useState) + TabBar
  modules/batteryApi.ts    получение данных (в ЛР5 — из mock; в ЛР6 здесь будут запросы к веб-сервису)
  modules/mock.ts          mock-коллекция (7 типов аккумуляторов с атрибутами)
  components/              TabBar, BatteryCard, CapacityFilter, ShortDescription, AttributesList
  pages/                   GridPage (плитка), FeedPage (лента)
public/                    DefaultImage.jpg, DefaultVideo.mp4 — медиа по умолчанию
```

## Хуки

- `useState` — значение фильтра, список карточек, загрузка, раскрытие описания, ошибка загрузки медиа.
- `useEffect` — загрузка плитки при монтировании; загрузка карточки ленты при смене `id` в адресе;
  загрузка списка для «Далее», если лента открыта по прямой ссылке.
- `useParams`, `useNavigate`, `useLocation`, `useOutletContext` — из react-router-dom.
